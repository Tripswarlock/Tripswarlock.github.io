# tripswarlock.github.io

Статическая страница-каталог инструментов для электронной подписи:
штамп, проверка и подпись PDF через КриптоПро CSP.

**Сайт:** https://tripswarlock.github.io/

## Что на странице

- QR-код для донатов (Ozon Банк) — в первом экране, с увеличением по клику;
- три проекта: «Штамп ЭП» (Qt), «Штамп ЭП — веб» (JavaScript), «Sign Everything» (Python);
- каталог всех репозиториев, связанных с подписью;
- принципы: локальная обработка, КриптоПро, проверяемый результат.

## Структура

```
index.html            — вся разметка
assets/styles.css     — оформление, тёмная и светлая темы
assets/app.js         — тема, фильтры, анимации, диалог QR
assets/donate-qr.png  — QR-код для приёма донатов
assets/stamp-ep.png   — скриншот нативного приложения
assets/pdf-sign-stamp.jpg — скриншот веб-версии
```

## Как обновить QR-код

1. Положите новый QR в `assets/donate-qr.png` (квадратный PNG, желательно от 600×600).
2. При необходимости поправьте подпись банка в `index.html` — блок `aside.donate`.

## Локальный просмотр

```powershell
python -m http.server 8080
# http://localhost:8080
```

## Публикация

GitHub Pages, ветка `main`, корень репозитория. Файл `.nojekyll` отключает обработку Jekyll,
поэтому все ассеты отдаются как есть.
